# AWS Deployment Overview

AWS allows organizations to deploy applications in secure, scalable cloud infrastructure.

This documentation focuses on production deployment using:

- EC2
- VPC
- S3
- RDS
- Load Balancer
- Auto Scaling Group

---

# Why AWS

Benefits:

- Scalability
- High Availability
- Fault Tolerance
- Security
- Global Infrastructure
